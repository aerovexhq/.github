# .github

Aerovex develops next-generation 3D simulation engines, digital twin environments, and mission operating systems for autonomous aerial, ground, and spatial robotics — bridging visual design, physics simulation, and real-world hardware teleoperation.

## Flagship Ecosystem Projects

- **Aerovex Workstation**: Unified 3D geospatial digital twin, Cesium terrain, CAD studio, and mission planner.
- **Chronos**: High-throughput multi-world 6-DOF simulation kernel, 8 dynamics solvers and aerodynamics.
- **Kestrel**: Hard real-time embedded flight control OS, 24-state EKF and multi-vehicle guidance.
- **Atoma**: 3D interactive quantum, atomistic, molecular and materials CAD studio in pure safe Rust.
- **Phonon**: Physically rigorous electro-thermal circuit simulator and transistor-level SPICE solver.
- **Axiom**: High-performance in-RAM HDL engine, Cranelift JIT simulator and silicon telemetry.
- **Sonon**: Minimalist robotics-aimed acoustic DSP, few-shot phrase spotting and streaming speech engine.
- **Vexview**: Minimalist media and video studio inspector, stream trimming and image editing engine.
- **Vexrec**: Screen and audio recording with Wayland PipeWire, loopback audio and camera PiP.
- **Appify**: Convert web applications into native desktop applications with Rust backend.
- **Vexel**: Statically-typed compiled systems and WebAssembly programming language (`@vexel-lang`).
